# 第9章：ReAct 模式

> ReAct = Reasoning(推理) + Acting(行动)，现代 Agent 框架的基石。

---

## ReAct 是什么？

**ReAct** 是一个循环：
1. **思考**：我现在需要做什么？
2. **行动**：调用一个工具
3. **观察**：工具返回了什么？
4. 重复，直到问题解决

```
┌──────────────────────────────────┐
│         ReAct 循环               │
│                                  │
│  → 思考: "我需要算什么？"        │
│  → 行动: 调用 multiply(15, 8)   │
│  → 观察: 得到 120               │
│  → 思考: "下一步算什么？"        │
│  → 行动: 调用 add(120, 160)     │
│  → 观察: 得到 280               │
│  → 思考: "算完了"               │
│  → 回答: "总价是280元"          │
└──────────────────────────────────┘
```

---

## 为什么需要 ReAct？

### 对比几种方法：

**方法1：直接问（零样本）**
```
"15×8+20×8等于多少？"
LLM: "279" ← 算错了！
```

**方法2：思维链**
```
"让我一步步算：15×8=120, 20×8=160, 120+160=279" ← 还是错了！
```

**方法3：ReAct（本章）**
```
思考: 先算 15×8
行动: multiply(15, 8)
观察: 120
思考: 再算 20×8
行动: multiply(20, 8)
观察: 160
思考: 加起来
行动: add(120, 160)
观察: 280
回答: 280 ✓ 正确！
```

> ReAct 把计算交给了真实的工具，所以不会算错。

---

## ReAct 的威力

| 能力 | 说明 |
|------|------|
| 可靠性 | 工具计算不会出错 |
| 透明性 | 每一步推理都看得见 |
| 可调试 | 出问题了能定位到哪一步 |
| 可扩展 | 加新工具就行，不需要改整体逻辑 |

## 代码关键点

```javascript
// 系统提示词定义了固定的模式
const systemPrompt = `
你必须遵循以下模式:
思考: [推理过程]
行动: [调用一个工具]
观察: [等待结果]
...
思考: [所有信息收集完毕]
回答: [最终答案并停止]
`;

// 循环执行
async function reactAgent(prompt, maxIterations = 10) {
    let iteration = 0;
    while (iteration < maxIterations) {
        iteration++;
        const response = await session.prompt(
            iteration === 1 ? prompt : "继续推理。",
            { functions, maxTokens: 300 }
        );
        // 检测到 "回答:" 就停止
        if (response.includes("回答:")) return response;
    }
}
```

## 谁在用 ReAct？

几乎所有现代 Agent 框架都基于 ReAct 模式：
- **LangChain** AgentExecutor
- **AutoGPT** 自主任务执行
- **ChatGPT 插件** 工具调用
- **各类企业 AI Agent**

---

## 一句话总结

ReAct = 思考 + 行动 + 观察，循环往复。它把 LLM 从不靠谱的"心算者"变成了可靠的"工具使用者"。这是从玩具到生产级 Agent 的关键一步。
