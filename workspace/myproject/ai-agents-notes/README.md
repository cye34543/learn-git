# AI Agents 从零开始 -- 学习笔记

本笔记基于 GitHub 开源教程 [ai-agents-from-scratch](https://github.com/pguso/ai-agents-from-scratch) 整理而成。

## 什么是 AI Agent？

简单来说，**AI Agent = 大语言模型(LLM) + 系统提示词 + 工具 + 记忆 + 推理模式**。

- **LLM** = 大脑（用来思考）
- **系统提示词** = 身份（定义角色和行为）
- **工具** = 双手（可以执行实际操作）
- **记忆** = 状态（记住过去的对话和信息）
- **推理模式** = 策略（如何一步步解决问题）

## 学习路线

以下15个章节按难度递进，建议按顺序阅读：

| 章节 | 主题 | 核心知识点 |
|------|------|-----------|
| 01 | 基础 LLM 交互 | 模型加载、提示词、令牌生成 |
| 02 | OpenAI 接口入门 | 云端API、温度控制、令牌计费 |
| 03 | 系统提示词与专业化 | 角色定义、行为约束、输出格式 |
| 04 | 推理与问题求解 | 逻辑推理、问题分解、推理局限性 |
| 05 | 并行处理 | 并发请求、序列管理、性能优化 |
| 06 | 流式输出 | 实时响应、令牌限制、用户体验 |
| 07 | 函数调用(工具使用) | 工具定义、JSON Schema、代理决策 |
| 08 | 持久记忆 | 跨会话状态、偏好存储、记忆检索 |
| 09 | ReAct 模式 | 推理+行动循环、多步骤求解 |
| 10 | 原子思维(AoT) | 结构化规划、依赖管理、可验证执行 |
| 11 | 错误处理 | 错误分类、重试策略、优雅降级 |
| 12 | 思维树(ToT) | 分支探索、评分剪枝、束搜索 |
| 13 | 思维图(GoT) | DAG编排、多源融合、冲突解决 |
| 14 | 思维链(CoT) | 分阶段推理、可审计决策、合规检查 |
| 15 | 工具路由(嵌入) | 相似度匹配、top-k筛选、固定工具 |
