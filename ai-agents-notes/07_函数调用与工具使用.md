# 第7章：函数调用与工具使用

> AI Agent 的分水岭 — 从"只能说"到"能做"。

---

## 什么是函数调用 (Function Calling)？

**函数调用** 让 LLM 不再是只能生成文字，而是可以**调用你定义的函数**来：
- 获取实时数据（比如当前时间）
- 执行计算（比它自己算得准）
- 操作外部系统（查数据库、调 API）

```
纯文字生成:                      Agent（带工具）:
LLM → 只能输出文本              LLM + 工具 → 可以执行动作

用户: "现在几点了？"            用户: "现在几点了？"
LLM: "抱歉，我不知道"           LLM 调用 getCurrentTime()
                               → 得到 "14:30"
                               → 回复: "现在是14:30"
```

**这就是"智能体"的本质 — 不光会说，还会做。**

---

## 怎么工作的？

```
1. 定义一个函数（工具）
   getCurrentTime: "获取当前时间"
   
2. LLM 看到可用工具列表
   可用函数:
   - getCurrentTime: 获取当前时间
   - getWeather: 获取某城市天气
   - calculate: 数学计算

3. LLM 自己决定什么时候用哪个
   "几点了？"   → 调用 getCurrentTime
   "5+5=？"    → 调用 calculate
   "讲个笑话"  → 不需要工具
```

---

## 代码示例

```javascript
const getCurrentTime = defineChatSessionFunction({
    description: "获取当前时间",    // LLM 根据这个判断何时调用
    params: {                       // 参数定义（JSON Schema）
        type: "object",
        properties: {}              // 无参数
    },
    async handler() {               // 实际执行的代码
        return new Date().toLocaleTimeString();
    }
});

// 使用时，把工具传给 session.prompt
const answer = await session.prompt("现在几点了？", { 
    functions: { getCurrentTime } 
});
```

---

## 完整执行流程

```
用户: "现在几点了？"
  ↓
LLM 想: "我需要当前时间，有个 getCurrentTime 可以用"
  ↓
LLM 输出特殊格式: {function_call: "getCurrentTime"}
  ↓
程序拦截，执行 handler()
  ↓
handler 返回: "14:46:36"
  ↓
LLM 收到工具结果，结合系统提示词处理（例如转成24小时制）
  ↓
最终回复: "14:46"
```

## 实际应用场景

| Agent 类型 | 需要的工具 |
|-----------|-----------|
| 个人助理 | 日历、邮件、提醒 |
| 研究助手 | 网页搜索、文档阅读 |
| 编程助手 | 文件操作、代码执行 |
| 数据分析 | 数据库查询、统计计算 |

---

## 一句话总结

函数调用是让 LLM 变成 Agent 的关键一步。没有它，LLM 只是"话痨"；有了它，LLM 就能真正干活了。定义好工具的描述和参数，LLM 会自己判断什么时候该用哪个。
