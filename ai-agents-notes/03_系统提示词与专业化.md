# 第3章：系统提示词与专业化

> 同一个模型，配上不同的"岗位说明书"，就变成了不同的专家。

---

## 什么是系统提示词？

**系统提示词** 放在对话窗口的最前面，它定义了 AI 在整个对话中的角色和行为。

### 类比
```
没有系统提示词              有系统提示词
───────────────            ───────────────
"你好，我是AI助手。"       "我是一名专业翻译，
"我能帮你做什么？"         擅长科学德文翻译，
                           遵守严格的质量标准。"
```

---

## 系统提示词的结构

```
┌──────────────────────────────────┐
│ 1. 角色定义                      │
│    "你是一个专业的科学翻译..."    │
├──────────────────────────────────┤
│ 2. 任务描述                      │
│    "你的目标是把英文翻译成德文..."│
├──────────────────────────────────┤
│ 3. 行为规则                      │
│    "始终...   绝不要..."          │
├──────────────────────────────────┤
│ 4. 输出格式                      │
│    "仅输出翻译结果，不要加解释"   │
├──────────────────────────────────┤
│ 5. 约束条件                      │
│    "使用科学风格、德语数字格式"   │
└──────────────────────────────────┘
```

---

## 好坏对比

### 差的系统提示词：
```
"翻译成德文"
```
结果：可能添加不必要的解释、术语不一致、输出格式混乱

### 好的系统提示词（详细版）：
```
"你是一位经验丰富的科学翻译专家，精通英译德。
规则：
1. 精确保留每个技术陈述
2. 使用地道的德语
3. 避免直译句子结构
4. 使用正确的技术术语
5. 仅输出翻译结果，不加任何解释"
```
结果：质量一致、术语正确、格式规范

## 常见的设计模式

| 模式 | 说明 | 示例 |
|------|------|------|
| 角色扮演 | 让模型扮演某种职业 | "你是一位医生..." |
| 规则约束 | 明确的行为准则 | "永远不要透露个人信息" |
| 格式控制 | 限定输出格式 | "一律返回 JSON" |
| 上下文注入 | 预置背景知识 | "以下是你需要知道的信息..." |

---

## 关键点

**同一个模型 + 不同的系统提示词 = 完全不同的 Agent**

你不需要训练新模型，只需要写好提示词，就能创造出翻译专家、代码助手、数据分析师等不同角色。

---

## 一句话总结

系统提示词是创建专业 Agent 的第一步。写详细一点、规则明确一点，结果就会稳定一点。这是从"随便聊天"到"专业工具"的分水岭。
