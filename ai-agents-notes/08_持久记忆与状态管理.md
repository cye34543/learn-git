# 第8章：持久记忆与状态管理

> 加了记忆，Agent 就不再是"金鱼记忆"了。关了再开，它还认得你。

---

## 有没有记忆的区别

```
没有记忆:                      有记忆:
会话1: "我叫小明，爱吃披萨"    会话1: "我叫小明，爱吃披萨" → 保存
会话2: "我叫什么？"            会话2: "我叫什么？"
Agent: "我不知道"              Agent: "小明！" ✓
```

---

## 记忆系统架构

```
┌──────────────────────────────┐
│       Agent 会话              │
│  系统提示词 + 已加载的记忆     │
│  + saveMemory 工具            │
└──────────┬───────────────────┘
           ↓
┌──────────────────────────────┐
│      记忆管理器               │
│  • 从文件加载记忆             │
│  • 保存记忆到文件             │
│  • 格式化后注入提示词         │
└──────────┬───────────────────┘
           ↓
┌──────────────────────────────┐
│   持久化存储(agent-memory.json)│
└──────────────────────────────┘
```

---

## 记忆的类型

```json
{
  "memories": [
    {
      "type": "fact",           // 事实
      "key": "user_name",       // 标识
      "value": "小明",
      "source": "user",
      "timestamp": "2025-10-29T11:22:57Z"
    },
    {
      "type": "preference",     // 偏好
      "key": "favorite_food",
      "value": "披萨",
      "source": "user",
      "timestamp": "2025-10-29T11:22:58Z"
    }
  ]
}
```

---

## Agent 怎么记住东西？

```
1. 用户说: "我叫小明，爱吃披萨"
2. Agent: "这是重要信息，我应该记住"
3. Agent 调用: saveMemory("fact", "user_name", "小明")
4. 写入 agent-memory.json
5. 下次启动时，从文件加载，注入到系统提示词

下次对话:
系统提示词 = "你是一个有帮助的助手"
            + "已记住的信息: 用户叫小明，爱吃披萨"
```

---

## 智能去重机制

这个例子的厉害之处是，Agent 会先**比较**再保存：

```
用户: "我叫小明"
Agent 检查记忆: user_name 已经是"小明"
Agent: "是的，我记得你叫小明。" (不重复保存)
```

```
用户: "我现在喜欢寿司了"
Agent 检查记忆: favorite_food 之前是"披萨"，变了
Agent: "好的，我更新了。" (只更新，不新增)
```

---

## 记忆系统的挑战

| 问题 | 解决方案 |
|------|---------|
| 记忆膨胀 | 按重要性排序，定期清理 |
| 信息冲突 | 看时间戳，最新的为准 |
| 隐私问题 | 加密存储，设置过期策略 |

---

## 一句话总结

记忆让 Agent 从"一次性工具"变成"持续相处的助手"。关键是：结构化存储 + 智能去重 + 注入系统提示词。这是打造个性化 Agent 的核心。
